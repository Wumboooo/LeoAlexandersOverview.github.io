Case Studies

Problems I solved on the job — what was wrong, what I did, what changed.

Slow ticket page

Performance · PostgreSQL / PHP

Problem: the ticket-create page full-scanned ~27k external rows on every load.
Fix: cached the branch options with a TTL and identified the missing indexes for serial search.
Result: the page no longer pays the full-scan cost per request.

Closed-app push notifications

Mobile · Flutter / FCM

Problem: technicians could miss new tickets when the app was closed.
Fix: an in-app feed plus Firebase push triggered from ticket events, with device registration.
Result: alerts reach technicians even when the app is not open.

Safer releases, three environments

Release · Flutter flavors / Shorebird

Problem: one build pointed at one API, which made testing risky.
Fix: dev / staging / prod Android flavors and per-flavor over-the-air patches.
Result: testing stays off production data and fixes ship without a full reinstall.
